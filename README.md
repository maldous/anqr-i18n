# ANQR i18n - Translations

This repository contains translation files for [ANQR](https://anqr.link), the QR code generator with image and animation support.

## Repository Structure

- **`master` branch**: This README and documentation
- **`locales` branch**: UI translation files (`*.txt`) for the app interface
- **`static` branch**: Static page content (`*.txt`) for About, Guide, Examples, etc.

## Contributing

Want to help translate ANQR? Here's how:

1. **Switch to the `locales` or `static` branch** to see the translation files
2. **Find your language file** (e.g., `fr-FR.txt` for French)
3. **Edit the translations** - each line has format: `ID=Translation`
4. **Submit a pull request**

### File Format

The `.txt` files use a simple tab-separated format:
```
ID<tab>Translation text
```

For example:
```
1	Generate QR Code
2	Download
3	Share
```

### Template Files

- `template.txt` - Contains all translation IDs with English descriptions
- Use this as a reference when translating
