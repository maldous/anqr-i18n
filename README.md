# ANQR Translations

![Languages](https://img.shields.io/badge/languages-87-blue)
[![Contributions Welcome](https://img.shields.io/badge/contributions-welcome-brightgreen.svg)](CONTRIBUTING.md)

This repository contains the translation files for [ANQR](https://anqr.link) - an advanced QR code generator with styling, overlays, and animations.

## 🌍 Contribute a Translation

**No Git knowledge required!** Click any edit link below to contribute directly in your browser.

### What's the difference?

- **Static** - Long-form content for pages like About, Guide, Privacy Policy, and Terms of Service
- **Locales** - Short UI strings like button labels, menu items, tooltips, and error messages
