594	"ನೇರ API URL: ಅಪ್ಲಿಕೇಶನ್‌ಗಳು, ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಅಥವಾ ಇತರ ಇಂಟಿಗ್ರೇಷನ್‌ಗಳಲ್ಲಿ ಬಳಸಲು ಕಚ್ಚಾ API URL."
595	"HTML ಉದಾಹರಣೆ"
596	"ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ QR ಕೋಡ್ ಅನ್ನು ಎಂಬೆಡ್ ಮಾಡಲು:"
597	"<img src=\"https://anqr.link/api/qr?data=https://yoursite.com&size=200\" alt=\"QR Code\" />"
598	"ಸ್ಪಂದಿಸುವ ಗಾತ್ರಕ್ಕಾಗಿ:"
599	"<img src=\"https://anqr.link/api/qr?data=https://yoursite.com&size=400\" alt=\"QR Code\" style=\"max-width: 100%; height: auto;\" />"
600	"ಸರ್ವರ್ ದೀರ್ಘ ಕ್ಯಾಶ್ ಹೆಡರ್‌ಗಳೊಂದಿಗೆ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಕ್ಯಾಶ್ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಅದೇ URL ಗಾಗಿ ಪುನರಾವರ್ತಿತ ವಿನಂತಿಗಳು ವೇಗವಾಗಿರುತ್ತವೆ."
601	"ಹಂಚಿಕೆ URL ಸ್ವರೂಪ"
602	"ವೃತ್ತಿಪರ ಮೋಡ್‌ನಲ್ಲಿ ಹಂಚಿಕೆ ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ, ANQR ನಿಮ್ಮ ಪ್ರಸ್ತುತ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು URL ಪ್ಯಾರಾಮೀಟರ್‌ಗಳಾಗಿ ಎನ್‌ಕೋಡ್ ಮಾಡುತ್ತದೆ. ಸ್ವರೂಪವು:"
603	"https://anqr.link/?data=...&ec=H&style=rounded&...."
604	"ಈ ಪ್ಯಾರಾಮೀಟರ್‌ಗಳು API ಪ್ಯಾರಾಮೀಟರ್‌ಗಳನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತವೆ, ಆದ್ದರಿಂದ ಮೂಲ ಮಾರ್ಗವನ್ನು / ನಿಂದ /api/qr ಗೆ ಬದಲಾಯಿಸುವ ಮೂಲಕ ಮತ್ತು ಅಗತ್ಯವಿರುವಂತೆ w/h ಪ್ಯಾರಾಮೀಟರ್‌ಗಳನ್ನು ಹೊಂದಿಸುವ ಮೂಲಕ ನೀವು ಹಂಚಿಕೆ URL ಅನ್ನು API URL ಗೆ ಪರಿವರ್ತಿಸಬಹುದು."
605	"ಗಮನಿಸಿ: ಸ್ಥಳೀಯ ಫೈಲ್‌ಗಳಿಂದ ಅಪ್‌ಲೋಡ್ ಮಾಡಿದ ಓವರ್‌ಲೇ ಚಿತ್ರಗಳನ್ನು URL ಮೂಲಕ ಹಂಚಿಕೊಳ್ಳಲಾಗುವುದಿಲ್ಲ — URL-ಆಧಾರಿತ ಓವರ್‌ಲೇಗಳು (img ಪ್ಯಾರಾಮೀಟರ್) ಮಾತ್ರ ಹಂಚಿಕೊಂಡ ಲಿಂಕ್‌ಗಳು ಮತ್ತು API ಕರೆಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ."
606	ದರ ಮಿತಿಗಳು ಮತ್ತು ಬಳಕೆ"
607	"ಸಮಂಜಸ ಪ್ರಮಾಣಗಳಿಗೆ API ಉಚಿತವಾಗಿ ಬಳಸಲು ಲಭ್ಯವಿದೆ. ಖಾತರಿಪಡಿಸಿದ ಅಪ್‌ಟೈಮ್ ಅಗತ್ಯವಿರುವ ಹೆಚ್ಚಿನ-ಪ್ರಮಾಣದ ಬಳಕೆ ಅಥವಾ ವಾಣಿಜ್ಯ ಅಪ್ಲಿಕೇಶನ್‌ಗಳಿಗಾಗಿ, ದಯವಿಟ್ಟು ನಮ್ಮನ್ನು ಸಂಪರ್ಕಿಸಿ."
608	"API ಪ್ರತಿಕ್ರಿಯೆಗಳು ಆಕ್ರಮಣಕಾರಿ ಕ್ಯಾಶಿಂಗ್ ಹೆಡರ್‌ಗಳನ್ನು ಒಳಗೊಂಡಿವೆ. ಉತ್ತಮ ಕಾರ್ಯಕ್ಷಮತೆಗಾಗಿ, ನಿಮ್ಮ ಕಡೆಯಲ್ಲಿ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಕ್ಯಾಶ್ ಮಾಡಿ ಅಥವಾ ಒಂದೇ ರೀತಿಯ QR ಕೋಡ್‌ಗಳಿಗಾಗಿ ಅದೇ URL ಅನ್ನು ಸ್ಥಿರವಾಗಿ ಬಳಸಿ."
